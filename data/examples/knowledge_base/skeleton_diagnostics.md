# Skeleton Diagnostics

## 受限骨架生成闭环

受限骨架阶段由 RAG + Skeleton Agent 生成一批候选骨架。validator 只使用正轨迹和反轨迹检查骨架是否存在成分冗余、成分缺失或逻辑算子错误。

## 通过数量要求

只有当至少两个受限骨架通过正/反轨迹诊断时，流程才进入 X/F/G 补全阶段。若通过数量不足，失败骨架的错误类型和轨迹证据会写入当前 RAG，并反馈给 Skeleton Agent 重新生成。

## 职责边界

skeleton_validator.py 不做 X/F/G 补全，不使用边界轨迹，也不负责完整候选公式评分。边界轨迹只在候选公式补全后用于区分 F、XF、X 等时序细节。

## 常见骨架错误

成分缺失：骨架缺少 trigger 或 response，或无法拒绝反轨迹。

逻辑算子错误：骨架过强、蕴含方向反了，或错误使用 and、or、not。

成分冗余：删除重复或恒真/恒假成分后，正/反轨迹诊断结果不变。

重复否定：`!!p` 与 `!(!p)` 都是非法骨架，因为括号不改变两个否定算子的
直接嵌套关系。`!(p & !q)` 合法，其中两个否定处于不同的布尔层级。只有
`X`、`F`、`G` 可以形成重复或混合的一元时序链，例如 `X X p`、`F G p`
或 `G X F p`；受限骨架阶段仍统一禁止出现具体 `X/F/G`。
